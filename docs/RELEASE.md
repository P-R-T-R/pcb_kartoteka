# Утвержденный релиз

Version: `0.9.1`

Published from source commit:

`653013529a0b921674c07fe3eab02582d19da0f6`

Утвержденные public stable images:

- Backend: `ghcr.io/p-r-t-r/pcb-kartoteka-backend-stable:0.9.1@sha256:97b1b277bf32ecd60e08cef97148918ca3be69203bafe2020b1a14b01b44561f`
- Frontend: `ghcr.io/p-r-t-r/pcb-kartoteka-frontend-stable:0.9.1@sha256:a85b791e676544fa9865714ed87ffde294ebb0a1f19d5e829423fd4bb9584fc4`

Основные изменения относительно `0.9.0`:

- номер удаленного объекта остается зарезервированным, пока объект находится в
  корзине, и освобождается после окончательного удаления;
- в окнах удаления всех поддерживаемых объектов можно сразу выбрать
  безвозвратное удаление;
- при создании новой ревизии платы разрешено изменить проект Altium;
- восстановлено добавление плат в сборки и изделия, улучшены связанные окна;
- для сборок добавлены исполнения с наследованием наименования и комментарием;
- исправлены компоновка таблиц, уведомлений и диалогов на широких и узких
  экранах.

Образы прошли тесты приложения, проверку содержимого, сканирование
HIGH/CRITICAL-уязвимостей, приемку на тестовом адресе и развертывание на
production владельца. Стабильные теги получены копированием утвержденного RC
без пересборки, поэтому digest совпадают с проверенным кандидатом. Перед
экспортом пакет дополнительно проходит анонимную чистую установку.

Пакеты stable доступны публично без аккаунта GitHub и токена; порядок описан в
`docs/REGISTRY_ACCESS.md`. Исходный репозиторий и RC-пакеты остаются приватными.
Не заменяйте эту версию тегом `latest`.
