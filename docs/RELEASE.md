# Утвержденный релиз

Version: `0.9.0`

Published from source commit:

`cdbb6a4f5173a0c6b76cdcfaeb4fd94084df6b00`

Утвержденные public stable images:

- Backend: `ghcr.io/p-r-t-r/pcb-kartoteka-backend-stable:0.9.0@sha256:c8b3bae30c4825247b137f900bd7ac7bb59902bfd9e3093505b743687ea35f6d`
- Frontend: `ghcr.io/p-r-t-r/pcb-kartoteka-frontend-stable:0.9.0@sha256:5922c56ea3b266e217e06657b9d1b1ecc84499dc954bae83f17afa360ab6806d`

Основные изменения:

- добавлена администраторская корзина с восстановлением и окончательным удалением;
- журнал изменений показывает понятный контекст объекта и проекта, а также
  поддерживает просмотр и восстановление версий;
- добавлен опциональный сервис Activity с отдельной базой данных и миграциями;
- удалена роль DevOps; поддерживаются роли «Администратор», «Редактор» и
  «Наблюдатель»;
- улучшены формы ЕСКД, сортировка классов и адаптивное отображение ревизий плат;
- добавлены эксплуатационные инструменты резервного копирования и проверки
  восстановления pgBackRest.

Образы прошли тесты приложения, проверку содержимого, сканирование
HIGH/CRITICAL-уязвимостей, приемку на тестовом адресе и развертывание на
production владельца. Стабильные теги получены копированием утвержденного RC
без пересборки, поэтому digest совпадают с проверенным кандидатом. Перед
экспортом пакет дополнительно проходит анонимную чистую установку.

Пакеты stable доступны публично без аккаунта GitHub и токена; порядок описан в
`docs/REGISTRY_ACCESS.md`. Исходный репозиторий и RC-пакеты остаются приватными.
Не заменяйте эту версию тегом `latest`.
