# Утвержденный релиз

Version: `0.9.2`

Stable-образы опубликованы 25.10.2026. Анонимное скачивание и чистая установка
проверены для указанных ниже digest, включая опциональный журнал изменений.

Published from source commit:

`c3036d6680c8d9a94167c79d37a178be715a73b0`

Утвержденные public stable images:

- Backend: `ghcr.io/p-r-t-r/pcb-kartoteka-backend-stable:0.9.2@sha256:1aabf7823f63e7a2f77b8bf1303f50966a22464057bdd5916cf14765e1633480`
- Frontend: `ghcr.io/p-r-t-r/pcb-kartoteka-frontend-stable:0.9.2@sha256:7002b4ef160fa11d557efc3a939021c7042e7ff730d318ed576225b0038b07ba`

Основные изменения относительно `0.9.1`:

- состав сборок поддерживает независимые позиции, повторяющиеся платы,
  выбор исполнения платы, замену и изменение количества;
- одна плата может входить в несколько сборок, составы исполнений независимы;
- уплотнены заголовки и таблицы сборок, исполнений и изделий;
- обновлены классификатор текстолита и форма его создания;
- окно создания текстолита полностью помещается в доступную высоту экрана.

Интеграционное API в этот выпуск не входит. При обновлении с `0.9.1` схема БД
последовательно переходит с `039` через `041` на `042`. До обновления обязательны
резервная копия БД и проверенный план отката; новые составы нельзя откатывать
простым понижением схемы.

Образы прошли тесты приложения, проверку содержимого, сканирование
HIGH/CRITICAL-уязвимостей, приемку на тестовом адресе и развертывание на
production владельца. Стабильные теги получены копированием утвержденного RC
без пересборки с сохранением digest. До экспорта пакета выполнена анонимная
чистая установка с проверками входа, прав доступа, CRUD, исполнений,
межпроектного состава изделий, ограничения запросов и изоляции контейнеров.

Пакеты stable доступны публично без аккаунта GitHub и токена; порядок описан в
`docs/REGISTRY_ACCESS.md`. Исходный репозиторий и RC-пакеты остаются приватными.
Не заменяйте эту версию тегом `latest`.
