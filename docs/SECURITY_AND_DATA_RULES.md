# Security and data rules

Дата фиксации: 2026-08-05.

## Главные правила

1. Исходники приложения не хранятся в этом репозитории.
2. Реальные секреты не хранятся в этом репозитории.
3. Клиентские данные не хранятся в этом репозитории.
4. База данных клиента не публикуется через git.
5. PostgreSQL не должен быть открыт в интернет.
6. Редактирование и админка требуют авторизации.
7. Публичный просмотр, если он будет включен, должен быть только read-only.

## Клиентский сервер

Клиент сам отвечает за:

- свой сервер;
- свой домен;
- HTTPS;
- свои учетные записи;
- свою базу данных;
- свои бэкапы;
- доступы DevOps.

## Наша зона ответственности

Мы должны предоставить:

- понятные Docker-образы;
- понятную инструкцию запуска;
- безопасные `.env.example`;
- миграции базы;
- healthcheck;
- backup/restore инструкции;
- инструкцию обновления;
- список требований к серверу.

## Секреты

В git можно хранить только placeholders:

```text
CHANGE_ME
generate-strong-secret
example.com
```

Нельзя хранить:

- реальные пароли;
- JWT secrets;
- database passwords;
- registry tokens;
- SSH keys;
- client admin passwords.
