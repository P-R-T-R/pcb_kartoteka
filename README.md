# PCB Kartoteka Deploy

Внешний репозиторий для развертывания PCB Kartoteka.

Этот репозиторий не содержит исходный код приложения.

## Что здесь будет

- `docker-compose.yml`
- `.env.example`
- nginx/reverse-proxy templates
- инструкции запуска
- инструкции обновления
- backup/restore инструкции
- ссылки на официальные Docker-образы

## Чего здесь не должно быть

- backend/frontend исходников;
- реальных `.env`;
- паролей;
- токенов;
- дампов базы;
- клиентских файлов;
- приватных данных.

## Модель использования

Клиент или DevOps берет этот репозиторий, настраивает `.env`, указывает домен,
подтягивает официальные Docker-образы и разворачивает сервис на своем сервере.

Исходный код продукта остается в приватном репозитории:

```text
https://github.com/P-R-T-R-AI/pcb_kartoteka_inner.git
```

## Статус

Репозиторий только создан. Полноценные compose-файлы и инструкции будут
добавлены после стабилизации продукта, исправления текущих багов и зеленого CI.
