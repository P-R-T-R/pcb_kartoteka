# PCB Kartoteka Deploy

Внешний репозиторий для развертывания PCB Kartoteka.

Этот репозиторий не содержит исходный код приложения.

## Состав

- `compose.yaml`
- `.env.example`
- nginx/reverse-proxy templates
- инструкции запуска
- инструкции обновления
- backup/restore инструкции
- ссылки на утвержденные Docker-образы

## Чего здесь не должно быть

- backend/frontend исходников;
- реальных `.env`;
- паролей;
- токенов;
- дампов базы;
- клиентских файлов;
- приватных данных.

## Модель использования

Клиент или DevOps берет этот репозиторий, настраивает `.env`, указывает домен,
подтягивает официальные Docker-образы и разворачивает сервис на своем сервере.

Исходный код, сборочная система и внутренняя документация продукта отделены от
этого репозитория. Клиент получает только версионированные образы и не передает
владельцу продукта свою базу, файлы, учетные записи или резервные копии.

## Статус

Репозиторий содержит рабочий шаблон установки. Перед запуском нужны имена
доступных клиенту образов, утвержденная версия и заполненный локальный `.env`.
Порядок запуска, обновления и восстановления описан в `docs/OPERATIONS.md`.
