# PCB Kartoteka Deploy

Публичный репозиторий для самостоятельного развертывания PCB Kartoteka на
сервере компании. Здесь нет исходного кода приложения, пользовательских данных,
учетных записей, паролей, резервных копий и доступа разработчика к установке.

## С чего начать

1. Прочитайте [запуск и обновление](docs/OPERATIONS.md).
2. Сверьте версию и два digest в [записи релиза](docs/RELEASE.md).
3. Настройте [доступ к приватным образам](docs/REGISTRY_ACCESS.md).
4. Настройте `.env` и сервер по [руководству администратора](docs/ADMIN_GUIDE.md).

Установка использует готовые приватные Docker-образы. Собирать приложение из
этой репы не нужно. Для скачивания нужен выданный компании read-only доступ.
Образы закреплены точными `sha256` digest; тег `latest` не используется.

## Состав

- `compose.yaml` и `.env.example`;
- защищенная конфигурация gateway в `nginx/app.conf`;
- `scripts/backup.sh` и `scripts/restore.sh`;
- клиентские инструкции в `docs/`;
- ограниченная лицензия на внутреннее использование установки.

Компания самостоятельно управляет доменом, TLS, пользователями, базой данных,
резервными копиями, мониторингом и реагированием на инциденты. Для просмотра
можно явно включить анонимный режим; запись и администрирование всегда требуют
учетной записи с подходящей ролью.
